# Changelog

Both packages share one version number and one fixture corpus, so an entry here applies to Python and JavaScript alike unless it says otherwise.

## Unreleased

- **Fixed, Turkish:** a dotted clock time after "saat" or with a suffix is read as a time (`14.00'teki` → on dörtteki, `saat 9.30'da` → saat dokuz otuzda, `09.00-17.30` → dokuz sıfır sıfır ile on yedi otuz); it was split into digits and a mis-harmonised suffix. A time on the hour with a suffix takes the suffix on the hour (`14:00'teki` → on dörtteki).
- **Fixed, both locales:** a spaced minus in an equation (`72 - 32 = 40`) is read as minus / eksi, not as a range.
- **Evaluation:** a held-out set of 60 real LLM answers (`eval/corpus/heldout.*.yaml`, generated by `speechready_eval.heldout`), scored against an independently written narration and reported apart from the headline numbers. Misreads 10% → 8% on 240 pairs; the two fixes above came out of it. `run --ids REGEX` runs a subset of the corpus.

## 0.3.0 (2026-11-02)

- **Bundled lexicon `tr-tech`:** foreign tech acronyms and names as Turkish developers say them, with English letter names (`API` → ey pi ay, `SQL` → es kyu el) and respellings (`JSON` → ceyson, `GitHub` → githab). `prepare(..., lexicon="tr-tech")` / `{ lexicon: "tr-tech" }`, or `load_lexicon` / `loadLexicon` for a copy to extend. Source of truth in `spec/lexicons`, bundled into both packages like the profiles.
- **Lexicon, Turkish:** a respelled word's apostrophe suffix is refitted to the spoken form (`API'yi` → `ey pi ay'ı`, `GPU'yu` → `ci pi yu'yu`, `API'si` → `ey pi ay'ı`).
- **Examples:** `examples/` has runnable LiveKit Agents (Python 1.8+, Node 1.9+) and Pipecat (1.15+) agents, checked against those versions' source, with the ElevenLabs SSML flag the break tags need.
- **Fixed, JavaScript:** `speechready/livekit`'s `textTransform` now returns a `ReadableStream`, which is what `@livekit/agents` chains in `ttsTextTransforms`; 0.2.0 returned an async generator that the SDK could not consume. A `ReadableStream` or any async iterable is accepted as input.
- **Evaluation scorer:** a Turkish acronym the speech-to-text wrote as letters (`NPM`) now matches the English letter names speechready writes out (`en pi em`); `25°C`, `™` and `&` are scored as the words every voice says; a Turkish `3.` before a lowercase word is the ordinal. These were scorer artefacts, not misreads, and they applied to both sides. Re-scored on the same recordings: misreads fell from 32% to 8% overall (English 29% to 7%, Turkish 37% to 10%), previously reported as 33% to 10%.

## 0.2.0 (2026-11-02)

- **Voice agents:** `speechready.integrations.livekit.text_transform()` for LiveKit Agents' `tts_text_transforms`, `speechready.integrations.pipecat.text_transform()` for a Pipecat TTS service's `text_transforms`, and `speechready/livekit` for LiveKit's Node SDK. No framework dependency: each returns the plain callable the framework expects.
- **Segmenter:** a fenced code block (``` or ~~~) is released as one piece once it closes, so a stream can drop or mention it instead of reading it line by line. New fixtures in `chunk-stream.yaml`.
- **Playground** runs the JavaScript package instead of Pyodide (35 kB instead of 10 MB).

## 0.1.0 (2026-11-02)

First release. The 0.0.1 versions on PyPI and npm were name placeholders with no code.

- **Pipeline:** `prepare(text, provider=..., model=...)` runs clean, verbalize, compile and chunk and reports every rewrite as a `Change`. Stages are also usable on their own.
- **Clean:** Markdown and LLM artefacts (headings, emphasis, links, fenced code, tables, emoji, URLs, emails) with an `Options` switch for each judgment call. Code blocks are dropped by default; `code_blocks="mention"` replaces one with a spoken sentence.
- **Verbalize:** English and Turkish rules for numbers, ordinals, decimals, fractions, percentages, currencies, dates, times, phone numbers, units, abbreviations and acronyms. Turkish applies vowel harmony to suffixes and, by default, reads foreign tech acronyms with English letter names.
- **Compile:** pause, spell and emphasis intents (`[pause 1s]`, `[spell ...]`, bold with `emphasis="intent"`) rendered to each provider's syntax: SSML, ElevenLabs break tags and v3 audio tags, Cartesia and Deepgram plain-text conventions.
- **Chunk:** sentence splitting for both locales, packing under each model's request limit in characters or bytes, and a streaming `Segmenter` that releases sentences from an LLM token stream as boundaries are confirmed.
- **Profiles:** ElevenLabs (v2 and v3/v4 families), OpenAI, Azure Neural, Google (Chirp 3 HD and the SSML voices), Amazon Polly, Cartesia, Deepgram, and `plain`. Profiles are YAML in `spec/profiles` and are bundled into both packages.
- **Lexicon:** one pronunciation file (IPA, respelling or spell-out per word) applied inline as phoneme tags where the provider supports them, exported as PLS for ElevenLabs, Azure and Polly, and as Google custom pronunciations.
- **Evaluation:** 1180 raw-versus-processed audio pairs across 7 providers and 16 voices, transcribed back with speech-to-text. Misreads on the targeted classes fell from 33% to 10% (English 30% to 8%, Turkish 39% to 13%). Listen at https://berkerbatur.github.io/speechready/.
- **JavaScript:** ESM package with type declarations, Node 20+, no runtime dependencies; passes the same 210 fixtures as the Python package.
